# Source-bound primary action proposals

Exact typed-primary alignment still rejects different action/target wording.
This repair does not declare paraphrases equivalent, weaken source quote or
modality checks, or certify an author's legal responsibility as fulfilled.

When a complete independently rejected review disagrees only about named action,
target, condition and/or applicability fields, the bridge can authenticate that
feedback and reserve one new primary proposal. Action disagreements use their
own `primary_action_reassessment_required` code and auditable rule. Grants remain
per clause, obligation and field. Unknown/empty actions, stale sources or partial
feedback cannot authorize a transition. Actor, quote, force, status, route,
classification, IDs and the requirement graph are frozen.

The primary rereads current source rather than copying a reviewer value. Its new
semantic proposal must pass the full validators and a fresh independent review.
The existing single proposal budget is shared with target/condition/applicability
proposals; it cannot reset on a later disagreement. Surplus typed proposal fields
can be discarded only by the audited parent-preserving field patch, followed by
the same authorization and fresh-review requirements. Human/external pending
duties remain pending and submission readiness remains false. No clause ID or
school-specific action wording is coded into this route.

no-duty disagreement which the explicit review-draft policy already recognizes.

an unrelated action/scope proposal. It is retained under

bindings, not put in the editable `source_atoms` list. Submission/unspecified
policy, malformed evidence and other incomplete inventories still cannot use
this exception. The one-shot budget and named-field grants are unchanged.

Validation operates on copies and rejects mutations rather than silently using
a projected reviewer opinion as authority. Reconstructing the feedback at budget,
projection and retry-authorization consumers also reconstructs the retained
assessments. Deleting/changing an assessment or editing its primary inventory is
not authorized. The next primary candidate still requires a fresh independent
review, followed by the usual draft-dispute ledger and non-release gates.
