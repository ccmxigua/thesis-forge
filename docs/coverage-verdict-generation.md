# Source-first coverage verdict generation

The fresh d97eaf5 BSU run failed when an independent reviewer described a
heading as establishing no duty, yet returned `incomplete` with no obligations.
Similar contradictions occurred on a sample value and a degree-category label.
These are observed outputs, not proof of a particular model-internal cause.
The conditional classification-correction wording in the long prompt is a
plausible contributor; its unrestricted interpretation is not the contract.

## Repair boundaries

- Informational is not inherently wrong. If independent reading finds no
  duty, the reviewer may explicitly return consistent, exact evidence and an
  empty inventory. Neither primary classification nor empty links proves this.
- Genuine omitted duties must still be enumerated as source-bound diagnostics.
  Typed mismatches and authorized pending-classification findings remain
  reportable; no atom, classification, requirement or source is auto-rewritten.
- Typed retry feedback is authenticated against the complete original request
  before its prompt-only view places disagreements next to their named check.
  Unrelated checks receive no correction record. The original request and
  source-reference packet remain unchanged; neighboring context is still only
  context, not selectable execution scope.
- Generation couples incomplete to a nonempty diagnostic inventory, preserving
  existing external/mixed/human/unsupported alternatives. Parsing intentionally
  remains compatible with rejected raw states so the original canonical
  validator and existing bounded corrective read remain authoritative.
- Native projection cannot enforce `minItems`; it retains the constraint as
  guidance. This is not a guarantee of model correctness or completeness.
  Empty incomplete remains rejected; no extra retry budget or score waiver.
