# Independent requirement selector identity

RR references identify requirements in the current check, regardless of an
atom's disposition. Previously only the generation-time `represented` branch
constrained these strings. An `unrepresented` atom could emit a shortened or
cross-check RR; compilation accepted it, then a generic semantic rejection
stopped the bridge before its existing bounded wire-correction route.

The source-reference schema now binds every disposition to the current
check's exact RR catalog in both generation and compilation. Without linked
requirements only an empty list is valid. The portable native item shape
offers no invented string selectors, but local validation remains mandatory.

This change never repairs a mistyped reference by similarity, changes a
disposition, or calls an unrepresented duty covered. Invalid provider output
is preserved and yields a source-reference contract rejection; the existing
bounded corrective reread uses the identical candidate. A syntactically valid
RR still needs all coverage, conditional, source and release validators.

Offline regressions cover every disposition, missing/shortened/foreign RR
selectors, checks with no links, native schema portability and semantic
contradictions after a valid selector. They are not proof of real BSU success.
