# Bounded independent uncertainty reread

An independent `uncertain` verdict cannot certify a candidate that still asserts
executable requirements. The original fail-closed test remains in force.

For covered/executable/verify-existing candidates only, a nonempty, wholly
ambiguous source inventory with current links and no registered machine,
manual, source-verification or pending-work facts can request one independent
reread. It cannot authorize a primary edit, a pass projection, omission of a
duty, a metadata guess or submission. Unrepresented and mixed dispositions are
not eligible. Genuine unresolved/unlinked primary uncertainty remains unchanged.

The typed rejection collects every eligible target. Its feedback includes the
unchanged candidate hash, current run/provenance/checks/request hashes and exact
rejected results. Both the feedback and immediately preceding native artifacts
must reproduce the rejection. Raw source selectors are invocation-bound, never
copied into the new invocation. Other individually validated checks are retained
with regenerated current source references, locked in generation schema and
verified again locally; hidden sibling errors fail closed. No sibling is silently
corrected or omitted. The native runner, bridge consumer and pipeline consumer
replay the same scope proof, even if success-facing hashes are resealed.

`primary_normative_basis` is now transmitted as an explicitly untrusted primary
interpretation, not a source fact. Template structure can justify placement or
literal preservation but does not automatically prove a field's metadata mapping.
The reread must assess both separately. Persisting ambiguity or another invalid
result exhausts the two-call independent-review budget and blocks the chunk.

The fixture preserves the selected C00009 check and observed raw/compiled result,
with original full-file hashes. It is an excerpt, not the full original invocation:
its old raw source selectors cannot bind its reduced request. Tests regenerate
selectors for that excerpt and exercise synthetic agreement/refusal against real
production validation paths. Mock-provider success is not live BSU/Word acceptance.
