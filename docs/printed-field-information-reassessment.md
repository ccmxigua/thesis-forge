# Printed-field classification reassessment

A current validator may reject a cover requirement that includes both executable
clauses and an informational clause with no obligations, even though the model
has already declared a typed printed field for that clause. This contradiction
does not establish that either interpretation is correct.

`source_information_reassessment.py` creates a bounded proposal opportunity only
when current source spans, evidence, complete validator facts, payload fingerprints
and the source-projection receipt bind the field to one informational review.
Clause IDs, school IDs, text and hashes are taken from the current request; there
are no BSU-specific identifiers. Source whitespace normalization is used only to
identify the proposed field. Exact source spans and quote validation remain bound
to the original source, and the independent reviewer still determines meaning.

The primary model may propose changes to the selected review's classification,
normative basis, reason and source-quoted obligations. It must freeze requirements,
fields, value bindings, conditions, edges, review order and all other reviews.
An ambiguous source must remain rejected, not be promoted by code. Existing
deterministic projections are replayed at the same stage on both candidates.

The bridge rebuilds the complete proposal from the current parent, checks the
allowed change set and full candidate contract, then requires a fresh independent
source-first review before accepting a chunk. A dispatch envelope alone never
authorizes acceptance. Original hard errors and raw responses remain in evidence;
proposal receipts explicitly deny mechanical semantic equivalence and submission
readiness. External, unresolved and previously atomized reviews are not eligible.
The proposal uses the ordinary retry budget, not an additional attempt allowance.

Offline tests cover valid proposals, payload/edge edits, unrelated errors, stale
source and run identities, foreign provenance, duplicate field matches, malformed
source quotes and contradictory retry guidance. These tests do not establish
real-provider agreement, successful BSU merge, DOCX generation or Word acceptance.
