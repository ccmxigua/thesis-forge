# Reconstruction validation scope

This runtime was reconstructed from the skills collection baseline c08232c. It is not a recovered copy of the original 2a9d823 runtime and does not inherit that version's historical full-suite results.

The current regression suite covers explicit formatting authority, source-style preservation, scoped active stories and page numbering, field/relationship integrity, drawing line-box/crop/visibility uncertainty, unresolved header content, keyword value spans, heading inheritance, paragraph spacing units, required-role observations and table scope. The reconstructed suite contains 96 synthetic tests; it is not the original project's full suite.

A Tianjin school-template test on the previously published runtime produced one independent candidate and one full render. Independent source and visual reviews held that candidate. The subsequent code repairs have synthetic coverage, but have not been verified by another real candidate or render. Do not claim the held candidate is repaired or submission-ready.

Body-text outline level is represented by 10; genuine heading levels 1 through 9 retain their meaning. Fresh semantic review must use the current contract. Do not reinterpret old reviewed responses in place.

Grouped subfigure/caption binding, final TOC refresh and native Word/WPS acceptance remain unresolved. Missing required fonts also limit render fidelity. Package integrity verifies exact declared bytes only, not visual correctness or school compliance.

Table receipts and visible scoring are reobserved after review-marker insertion and checked again against the final serialized document. If a marker breaks caption adjacency, the complete pre-marker table population is required; otherwise the table scope remains unresolved and its properties are unverified; this does not repair that layout.
