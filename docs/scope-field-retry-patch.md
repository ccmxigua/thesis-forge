# Per-atom scope proposal patches

A mixed independent-review feedback code is not a blanket grant to edit every
atom's target, condition or applicability. The complete source-bound feedback
specifies the allowed fields separately for each clause and obligation identity.

On an otherwise unchanged retry, surplus scope-field edits may be recorded and
discarded. The bridge builds a candidate on the authenticated parent, copying
only the exact named fields from the primary proposal. It never copies a value
from the rejected reviewer, changes the authorization set, or replenishes the
single shared scope-proposal budget. Quotations, requirements, identities,
classification, routing and other edits are still rejected by this narrow path.

The complete rejected request/review is reconstructed against current source,
candidate and run identity. Unique unchanged atom locations and source bindings
are required. The resulting patch must pass the existing scope authorization
verifier, full contract validators, and a fresh independent source-first review.
Parent/proposal/patch and feedback/source hashes, exact accepted fields and
discarded paths remain in the audit. This is a new semantic proposal, not proven
equivalence or compliance. No submission readiness is established.
