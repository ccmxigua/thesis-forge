# Source routing and declaration representations

These repairs derive identities and exact text from the current input. No
school, clause ID, evidence ID, or quotation is a global exception.

## Keyword provenance (classification policy v7)

A closed compound selection/verification action can use a split target that
explicitly identifies keywords originating in the current thesis. An exact
quotation may omit its subject only when the entire uniquely bound clause is
a registered pure keyword-origin instruction and the quotation itself retains
both selection-from-thesis and traceability predicates. Half quotations,
mixed duties, conditional claims, stale sources and unrelated targets cannot
authorize this projection. Typed actor/action/target/quotation/modality remain
unchanged for fresh independent review. Human verification remains pending;
this is not an automatic format requirement or proof of compliance.

## Fixed declaration text

An exact scalar `body` is removed only if it equals the first current source
paragraph and the supplied `body_parts` already equals the entire ordered
source paragraph list. The unique physical declaration candidate, current
span hashes, evidence selection and executable edges are still mandatory.
The audit retains the original scalar and its digest. A distinct, shortened,
trimmed, reordered or partially supplied body is never silently repaired.

Both merger and resource registry use one byte-preserving accessor. Legacy
scalar-only and array-only forms remain supported. Competing nonempty forms
are rejected at the Host contract and consumer boundaries; the registry does
not silently drop one, and the merger does not concatenate both. Empty/null
compatibility fields are not substantive competing text.

## Validation boundary

Captured first-attempt BSU chunk 4 now passes the full local candidate
validator and routes keyword provenance to pending human verification. Its
second attempt has a provably redundant body alias, but unrelated obligation
reason/route changes remain subject to drift rejection. This replay does not
invoke a model or establish independent semantic acceptance. Fresh BSU and
Word acceptance must be reported separately. `submission_ready=false` remains.
