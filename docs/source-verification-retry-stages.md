# Source-verification retries across candidate stages

An independent source reviewer authorizes a classification correction against
the complete, locally validated candidate. A raw response hash is not that
candidate hash: fixed declaration text, source constraints and other audited
deterministic projections may have changed its representation.

The bridge now reproduces both full candidates from the raw parent and the new
model proposal before checking the independent correction's response/semantic
hashes. The proposal must change only the explicitly named classifications.
Requirements, reasons, atomic obligations, route values, source quotes, conditions,
order and diagnostics remain frozen in the model response. Unknown/stale sources,
foreign provenance, changed payloads or unrelated errors do not gain authority.

After an informational clause becomes `requires_source_verification`, an existing
atom's responsibility route can conflict with that classification. The existing
metadata projector derives the human route from the authorized classification,
but only for validator-named route errors on those same reviews. Its exact source
binding, before/after hashes and complete projection are recorded separately from
the model's change. No actor, action, target, condition, force, applicability,
status, quote or requirement is edited by this route projection.

This is not permission to mark existing thesis content verified. The response
still requires a fresh independent source review and all ordinary contract gates.
The human-verification obligation remains visible, with submission readiness
false. A fresh independent rejection cannot publish or merge the candidate.

Regression tests exercise non-BSU clause IDs, source-driven constraint compilation,
complete candidate hashes, raw classification-only proposals, code-owned route
proofs, negative payload/source/identity cases and native-adapter orchestration.
Provider responses in those tests are mocked. Captured real responses are replayed
offline without editing the originals; neither form proves final BSU/DOCX/Word
acceptance.
