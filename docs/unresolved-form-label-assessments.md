# Unresolved form-label source assessments

Policy `source_bound_unresolved_form_label_assessment_v1` separates the primary
candidate's uncertainty from the independently identified source inventory.
A source-first reviewer need not invent an obligation merely because the primary
classified a standalone form label as unresolved.

Eligibility is deliberately narrow: the whole selected source must be a short
alphabetic label, with its original colon and exact table evidence, a complete
unmerged row and blank following cell. Every primary atom must remain unresolved
with unknown force, applicability, responsibility route and no actor/action or
condition. No linked requirements, known source facts, registered ambiguity,
verification/authoring work or mixed duty qualifies. These are review eligibility
checks, not an inference of field meaning from geometry. Other sources use the
existing review and missing-inventory gates.

Only a fresh source-first consistent/empty assessment citing the complete exact
label can qualify. Code never creates a source obligation, reclassifies the
primary, changes raw output, chooses a cover field or supplies missing values.
The analysis ledger separately records the source/check/result hashes and the
complete unresolved primary inventory. The consumer rebuilds this record from
the current request and validated response, not from a resealed sidecar.

The merged semantic ledger retains the primary unresolved atoms; requirements
completeness still lists the unresolved clause and creates its bound question.
Review-draft markers retain that question. Full and submission gates remain
closed, and no source assessment is evidence of document compliance or authority
to submit. An empty AO source inventory is not a claim that the primary question
was answered. Original runtime artifacts remain the acceptance evidence; the
reduced captured fixture and offline tests are not a new provider invocation.
