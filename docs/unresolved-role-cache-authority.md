# Unresolved rule projections are not execution authority

During a complete clause review, an explicitly unresolved clause has no accepted
formatting requirement. Its exactly source-bound deterministic role-cache leaves
must therefore be isolated before application, just like other non-executable
classifications. This is not reclassification, acceptance or a new font choice.

Accepted replacement properties remain protected. Missing clause reviews,
invalid evidence binding and surviving unreviewed contributors are not guessed
away. The existing isolation audit records source requirement IDs, clause IDs,
evidence IDs and removed/restored leaves. Manual obligations stay unresolved.

Regression example: a title-page clause misidentified as an abstract heading
must not leave a 14pt/single-spaced role cache that overwrites a source heading
while the accepted requirement asks only for page_break_before. Native visual
acceptance remains separate from source-format preservation.
